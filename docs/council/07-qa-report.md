# 07 - QA Report (expert QA, live web build)

Build under test: https://im-rudra.github.io/attendance-alamin/ (About screen: version 1.0.0 (47)). Device date during testing: Sat 2026-11-21 (so only the Overdue level of the warning ladder could be exercised, see "could not test").

Method and limits (be aware when reading this report):
- Browser pane is ~619x690 CSS px. Emulated sizes used: 1000x640 ("desktop", the largest that fits the pane without cropping) and 375x812 ("phone"). A true 1280+ wide Windows layout was NOT visible.
- Flutter canvas repaints lazily in the hidden pane, so screenshots lag one action; all results below were re-checked after a wait.
- Languages: mostly Bangla dark on desktop, English light on phone. Theme was switched to Light explicitly (so "follow OS dark" was not verified).
- File picker / share sheet cannot be driven by this harness. Backup export was captured by hooking the download anchor; import was done by injecting the captured blob into the file input.

## Verified working

- Onboarding: 4 steps; empty name gives "নাম লিখুন"; phone validation rejects 12 digits with example; duplicate guardian phone for two students accepted (siblings); very long Bangla name wraps/ellipsises in lists and roll call; weekly slots Sat/Mon/Wed with auto end = start+60; prepaid/postpaid choice and fee.
- Student form: join date after day 15 (21 Nov) defaults first billable month to Dec 2026 (matches scenario 6); month list allows earlier months.
- Schedule: 10:30-11:30 against 10:00-11:00 on Sunday is blocked live with the clashing item named ("প্রতি রবিবার ... ১০:০০-১১:০০") and two suggestions (earlier 9-10, later 11-12); tapping the 11:00-12:00 suggestion saves (touching allowed); "effective from" sheet appears on slot save. Reschedule of Physics A to Sun 22 Nov 11:00 correctly refuses its own batch's class and offers 12:00-1:00; saving that gives two Physics A classes on one day. Week view starts Saturday, shows the dashed origin marker "-> 22 Nov 12:00". Cancel shows snackbar with "tell guardians" and Undo.
- Roll call: default all present, tap toggles absent, late chip, live counts (2/1/1), save, Home shows 1/1 taken, 75 percent (present+late), roll call layout 2-column with side summary on desktop.
- Payments: partial 600 of 1000 shows "Partial - 400 left"; multi-month 3000 allocates Nov, Dec, Jan and part of Feb with a correct preview ("2,600 goes in advance"); fee change to 1200 from Dec honoured (Dec chip "Paid in advance"); delete payment recomputes (Nov back to "Partial 600 left"); triple-click on record produced a single payment.
- Dues list: overdue group, partial label "Overdue - Partial - 400 left", filters, "Remind everyone", total and severity bar. Collection summary numbers (Expected 1,000 / Received 600 / Outstanding 400; later 1,000/1,000/0), cash-in by method, other income 500 total 1,100.
- Exports: CSV payments file has UTF-8 BOM and Bangla names intact; backup file generated (2,444 bytes, name coaching-backup-2026-11-21-0631.ambackup); import via injected file shows Review screen with consistent counts and says older backup does not overwrite newer data.
- Settings/theme: language switch is instant, persists across reload; Light theme applies instantly and persists; Home, More, Students, Fees readable in light; search matches Bangla digits "০১৭১১" against ASCII-stored phone numbers; bilingual labels everywhere seen.
- Phone layout: bottom nav with Fees badge, Home, Batches, student profile, edit form all fit at 375 px with no horizontal page scroll (month chip row scrolls inside its card).

## Could not test (need a real device or a longer clock)

- Android: local class notifications and lead time, notification tap -> roll call, exact-alarm permission, real OS share sheet, photo picker, back-button behaviour, system dark mode following (theme was set to Light explicitly).
- Windows: native window resizing beyond 1000 px, window min size, keyboard shortcuts (Ctrl+K did nothing in the browser; the roll call "Keyboard shortcuts" panel was not exercised), real file dialogs.
- Time-based escalation levels L1-L5 and postpaid "upcoming" (device date fixed on the 21st, so only Overdue was reachable); no way to set the clock.
- Not reached for lack of time: Left student and grey group, archive/unarchive clash banner, holiday range + undo, waive month, second class same-day roll call save, bulk add in batch, enrolling a student in a second batch, extra class, edit receipt, payment methods/templates/reminder-lead settings editing, reduced effects, 0-fee student, rapid taps beyond the payment button, 300-student search speed.
